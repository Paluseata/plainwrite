Version 1.08

A retro word processor inspired by the AlphaSmart Neo and the King Jim Pomera. Eight files that save as you type, no distractions, and it works offline.

Open it

  • English (language packs download when you want them)
  • Multilingual (48 language packs built in)

Open it once while online, then add it to your home screen. It works offline from then on.

Other versions

  • Android and desktop (Windows, macOS, Linux) apps are built from the GitHub repository.

What's new in 1.08

  • Open a .txt file into a file slot from the Send menu.
  • A Caps Lock block in the bottom right corner of the screen.
  • Focus mode in the Android app.
  • Games are off by default; switch them on in Control Panel.
  • Filipino spell check, using a Tagalog word list.
  • Tapping the screen puts the cursor where you tapped again.
