はじめに

画面をタップするか、キーボードで打ち始めてください。打った文章は自動で保存されるので、保存ボタンはありません。文章はこのブラウザの中、この端末だけに保存されます。

日本語入力

Plainwrite-J には、昔のワープロのような日本語入力が入っています。キーボード(物理キーボード)で使えます。スマートフォンやタブレットの画面キーボードは、それぞれの日本語入力をそのまま使います。

  • 入力モード: 上のバーの表示が あ(ひらがな)、カ(カタカナ)、Ａ(全角英数: 英字・数字・記号が ＡＢＣ１２３ のような全角に、空白も全角に)、A(直接入力)を示します。タップで切り替え。キーボードでは 半角/全角、Ctrl+Space、Alt+` でオン・オフ。Mac では かな と 英数。コントロールパネル → 日本語入力 でも切り替えられます。
  • コントロールパネル → かな入力 で入力方式を選べます:
    • ローマ字(標準): ka→か、shi・si→し、kya→きゃ、nn→ん、子音を重ねると っ(kitte→きって)、xa・la→ぁ、-→ー。z のあとに h j k l で ←↓↑→、z. で …。大文字はそのまま英字になります。
    • JISかな(たていすかんな): 日本語キーボードに刻印されたかなの位置で入力します。@ が ゛、[ が ゜ で、前のかなにつきます。USキーボードでは ろ が `、ー が Shift+` です。
    • 親指シフト(NICOLA): 左親指キーは 無変換・英数・左 Alt/Option、右親指キーは 変換・かな・Space。文字キーと親指キーを同時に(前後0.1秒以内)押すとシフト面のかなになります。右親指キーを単独で押すと空白、または変換です。
  • 変換: 打ったかなには下線がつきます。Space(または 変換)で変換。文節に区切られ、変更中の文節は反転表示、その候補は一番下の行に、ステータス表示と同じように並びます。
    • Space・↓: 次の候補。Shift+Space・↑: 前の候補。1〜9 で下の行から直接選択。Page Down/Page Up で候補のページ送り。
    • ← → で文節を移動、Shift+← → で文節を短く・長く。
    • Enter で確定。Esc・Backspace でかなに戻ります。そのまま次を打つと確定して続けます。
    • F6 ひらがな、F7 カタカナ、F8 半角カタカナ、F9 全角英字、F10 半角英字。かなを入力中のときだけ働き、それ以外は F1〜F8 はファイルの切り替えです。
    • 選んだ候補は覚えて、次から先に出ます。コントロールパネル → キーボード設定 → 変換の学習をリセット で消せます。
  • かながないときの Space は全角の空白、Shift+Space は半角の空白です。
  • 辞書は SKK-JISYO.L(約15万語)です。初めて変換するときに読み込み、そのあとはオフラインでも使えます。80年代のワープロのように簡単な規則で文節に区切るので、長い文は区切りを間違えることがあります。そのときは Shift+← → で直すか、文節ごとに変換してください。
  • コントロールパネル → 全角表示 をオンにすると、英字・数字・記号を画面上で全角で表示します。昔のワープロのような見た目です。ロシア語のキリル文字も Pixel Gothic の全角の字形で表示します。表示だけの設定で、ファイルの文字は変わりません。Unicode には全角のキリル文字がないので、ほかのキリル文字(Ї、Ў、Қ など)は半角のままです。
  • コントロールパネル → 本体の表示 で、キーの表示を日本語(電源、印刷、ファイル１…)と英語で切り替えられます。長い表示はキーの幅に合わせて縮めます。
  • 標準の書体は Pixel Gothic です。日本語を使うとき(日本語のメニュー、またはファイルに日本語があるとき)は、日本語のない書体のかわりに画面全体を Pixel Gothic で表示し、一つの書体にそろえます。選んだ書体のまま日本語の文字だけを Pixel Gothic から借りるには、コントロールパネル → 他の書体の日本語 を 混ぜて表示 にしてください。

本体を動かす

本体はページの上で動かせます。マウスでは本体をドラッグ、タッチ画面では Plainwrite のロゴの帯を長押ししてから指を動かします。その帯をダブルクリック(ダブルタップ)すると元の場所に戻ります。コントロールパネル → 位置 で「動かせる」か「固定」を、置き場所 で中央・上・下・四隅を選べます。

8つのファイル

  • ファイル１〜ファイル８ のキーで、それぞれ別の文書を開きます。各ファイルはカーソルの位置を覚えています。
  • ファイル削除 で今のファイルを削除します。Y(はい)で削除、N(いいえ)で取り消し。
  • キーボードでは F1〜F8 または Alt+1〜8。

移動と選択

  • 文章をタップするとそこにカーソルが移ります。矢印、Home、End は画面上の折り返しに沿って動きます。
  • Shift+矢印で選択。切り取り、コピー、貼り付け、すべて選択も使えます。
  • Insert で挿入と上書きを切り替えます。コントロールパネル → カーソル でブロック・縦線・下線を選べます。
  • スマートフォンでは本体の下の ← ↑ ↓ → でカーソル移動、↵ で改行(変換中は確定)。

上のキー

  • 電源 で画面を消します。もう一度押すとつきます。コントロールパネル → 電源設定 で自動オフ(標準10分)、電源オンの方法、キーで起動、電池の表示。キーで起動がオンのときは、自動オフのあと5分間、電源ランプが点滅します。
  • 検索: 言葉を入れて Enter で検索。もう一度 検索 と Enter で次へ。検索欄は日本語入力に対応していないので、日本語を探すときは画面キーボードか貼り付けを使ってください。
  • ホーム / エンド: 行の先頭・末尾。アプレット でアプレットのメニュー、送る でファイルを送信・保存。印刷 はまだ使えません。スペルチェックは、カーソルから文末まで、続いて先頭から英単語を確かめます。日本語の部分は飛ばします。←→で候補・スキップ・辞書に追加を選び、↵で実行、escで終了。英語の辞書は初回にダウンロードし、そのあとはオフラインでも使えます。

メニュー

↑ ↓ で選び、↵ で開き、← → で設定を変えます。項目を直接タップしても選べます。esc か Backspace で戻ります。

アプレット

  • ワープロ: 文章を書く画面です。
  • 電卓: + − * / ( ) ^ と %。ans または演算子から始めると前の答えから続けます。
  • タイピング練習: 英語のキーボード練習です(ホーム段、上段、下段、数字、文)。
  • ゲーム: ヘビ、恐竜ジャンプ、英語クイズ、サイモン。ゲームの行で ← → を押すと難しさを変えられます。
  • 英語クイズ: どれも10問で、答えは矢印と ↵、1〜4 のキー、またはタップで選びます。類義語・対義語(同じ意味か反対の意味の英単語)、日本語→英語、英語→日本語、過去形(不規則動詞)、複数形(不規則なもの)、つづり。クイズごとに難しさと最高点があります。やさしいは3択、ふつうは4択、むずかしいは4択で、どれも紛らわしい答えになります。

書体

  • Aa キー、コントロールパネル → フォント、または Ctrl+Alt+F。大きさは4〜12行。
  • Pixel Gothic は DotGothic16 をもとにした書体で、キリル文字を半角で描き直し、ウクライナ語、ベラルーシ語、セルビア語、マケドニア語、カザフ語、キルギス語、モンゴル語の文字を加えています。
  • フォントを読み込む… で .ttf .otf .woff .woff2 を追加できます。

画面と本体

  • コントロールパネル → 画面: 液晶、アンバー、紙、ピンク、そして C64 や Apple II などのコンピュータ画面。ダークモード、文字と背景の濃さ、パレット編集で自分の色。
  • 本体の編集: 本体の色、画面サイズ、キーの色、面取り、カスタムCSS。
  • 下の段の最後のキーで全画面になります。

送信と保存

  • コンピュータに入力: 本体の下の欄に文章を打ち出します。コピーや .txt 保存ができます。
  • テキストファイルに保存: .txt で保存します(スマートフォンでは共有メニュー)。
  • 文章はこの端末のこのブラウザにだけあります。ブラウザのデータを消すと消えるので、大事なものは保存してください。

オフラインとインストール

  • 一度オンラインで開けば、そのあとは通信なしで使えます。
  • Safari: 共有 → ホーム画面に追加。Chrome: メニュー → アプリをインストール。
