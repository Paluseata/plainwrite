# Plainwrite-K (한국어판)

레트로하고 단출한 워드프로세서 Plainwrite의 한국어판입니다. 한 번 열고 나면 인터넷 없이도 동작합니다.

## AI 사용 고지

이 프로그램은 Anthropic의 인공지능 대형 언어 모델인 Claude의 도움을 받아 작성되었습니다.

## 판

- **한국어판**: 메뉴와 도움말이 모두 한국어입니다.
- **영어–한국어판**: 영어와 한국어 메뉴. 시스템 언어가 한국어이면 한국어로 시작합니다.

두 판 모두 같은 한글 입력기, 글꼴, 한자 표를 씁니다.

## 한글 입력

실물 키보드에서 동작합니다. 휴대폰과 태블릿의 화면 키보드는 원래의 한글 입력을 그대로 씁니다.

- **한글 자판**(제어판 → 한글 자판): 두벌식, 세벌식 390, 세벌식 최종, 로마자(로마자 한 글자가 자모 하나: `hangug'eo` → 한국어).
- **한/영 전환**: 위쪽의 한 / Ａ / A 표시, 한/영 글쇠, Shift+Space, Ctrl+Space, 또는 오른쪽 Alt만 눌렀다 떼기.
- **한자**: 한자 글쇠, F9, 또는 오른쪽 Ctrl만 눌렀다 떼면 커서 앞 글자(또는 선택한 글자들)를 한자로 바꿉니다. 후보는 맨 아래 줄에 많이 쓰는 순서로 나옵니다.
- **한자 표**: LibreOffice의 한글–한자 표, `dict-ko.txt` (MPL 2.0).

자세한 글쇠는 도움말에 있습니다. 애플릿 메뉴에는 **한글 타자 연습**(두벌식 자리, 낱말, 짧은 글, 분당 타수)과 **한자 연습**(8급 한자의 훈음을 보고 한자 글쇠로 입력)도 있습니다.

갈무리(이민서), Neo 둥근모(Dalgona., 김중태의 퍼블릭 도메인 원본), 해례본을 본뜬 정음, DotGothic16을 고친 Pixel Gothic K, Noto Sans CJK KR, Lora는 모두 SIL Open Font License 1.1입니다(`OFL.txt`). 한자 표는 MPL 2.0입니다(`MPL-2.0-dictionary.txt`).
